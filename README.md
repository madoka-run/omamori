# 不安対処アプリ「omamori」

RUNTEQ「バトルオブランテック」個人ハッカソン提出物です。

## サービス概要

不安やパニック発作に襲われたときに、呼吸法やグラウンディングなどの対処法をガイドし、不安の経過時間を記録できるアプリです。

## デモ

https://omamori-r0oe.onrender.com/

## このサービスへの思い

私自身が不安感（軽いパニック）が強く出る症状を経験し、不安に襲われたときに「今すぐ使える」対処法が必要だと感じました。

## 主な機能

- 今の不安レベル（1〜5）を選んで記録開始
- 呼吸法（4-4-4呼吸・5サイクル）を、フェーズ（吸う/止める/吐く）ごとに色分けした表示と、フェーズに連動して動くクローバーの演出とともに実践
- 呼吸法の途中でも「記録を終了する」「今の記録をやめる」でいつでも切り上げ可能
- グラウンディングやホットラインなど、他の対処法をカード形式で提案（タップで詳細をポップアップ表示）
- 不安が始まってから終わるまでの所要時間を記録・一覧で振り返り（1時間を超える場合は「X時間X分」表示）
- ログイン前に記録したログも、後から新規登録・ログインすることで自分のアカウントに紐付け
- 未ログイン時は、Cookieで発行した端末ごとの識別子で過去ログを絞り込み、他の匿名ユーザーの記録が見えないようにプライバシーに配慮
- 記録中は、どのページに移動しても右上に「不安記録中」のバッジが表示される


## 開発の背景・工夫した点

- 不安の最中でも操作に迷わないよう、1画面1アクションを意識したシンプルなUI
- 呼吸法の実践中はクローバーの葉が、吸う/吐くのフェーズの秒数に合わせて1枚ずつ時間差で表示・消滅し、視覚的にもペースを合わせやすいよう演出
- 「タイマーがあることで焦りを感じる人もいる」という配慮から、実践中はあえて経過時間を表示せず、記録が終わった後の画面・履歴でのみ確認できる設計にした
- ログイン前でも記録を開始でき、後から会員登録すればログを引き継げるようにして、利用のハードルを下げている

## 使用技術

- Ruby 3.2.2 / Rails 7.1.6
- PostgreSQL 14
- Devise（認証）
- Stimulus.js（importmap）
- Docker Compose

## テーブル設計（概要）

- `User`：Deviseによる認証情報を保持
- `AnxietyLog`：不安レベル（`anxiety_level`）、開始・終了日時（`started_at` / `ended_at`）を記録。`user_id`で`User`に紐付く（未ログイン時は`user_id`が`nil`のまま記録可能）。未ログイン時は`device_token`（Cookieで発行した端末ごとの識別子）でも記録を紐付け、匿名ユーザー同士のログが混ざらないようにしている

## ローカル環境構築

```bash

cd omamori
docker compose build
docker compose run --rm web bin/rails db:create db:migrate
docker compose up
```

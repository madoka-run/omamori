# 不安対処アプリ「omamori」

RUNTEQ「バトルオブランテック」個人ハッカソン提出物です。

## サービス概要

不安やパニック発作に襲われたときに、呼吸法やグラウンディングなどの対処法をガイドし、不安の経過時間を記録できるアプリです。

## デモ

https://omamori-r0oe.onrender.com/

## このサービスへの思い

私自身が不安感（軽いパニック）が強く出る症状を経験し、不安に襲われたときに「今すぐ使える」対処法が必要だと感じました。

## 主な機能

- 今の不安レベル（1〜5）を選んで記録開始
- 呼吸法（4-4-4呼吸・5サイクル）を画面と一緒に実践
- 呼吸法終了後、「もう一度やる」「他の方法を試す」「落ち着いた」から選択
- グラウンディングやホットラインなど、他の対処法の提案
- 不安が始まってから終わるまでの所要時間を記録・一覧で振り返り
- ログイン前に記録したログも、後から新規登録・ログインすることで自分のアカウントに紐付け

## 開発の背景・工夫した点

- 不安の最中でも操作に迷わないよう、1画面1アクションを意識したシンプルなUI
- 呼吸法の実践中は花びらの見た目が吸う/吐くに合わせて増減し、視覚的にもペースを合わせやすいよう演出
- 「タイマーがあることで焦りを感じる人もいる」という配慮から、経過時間表示は隠せる設計を予定
- ログイン前でも記録を開始でき、後から会員登録すればログを引き継げるようにして、利用のハードルを下げている

## 使用技術

- Ruby 3.2.2 / Rails 7.1.6
- PostgreSQL 14
- Devise（認証）
- Stimulus.js（importmap）
- Docker Compose

## テーブル設計（概要）

- `User`：Deviseによる認証情報を保持
- `AnxietyLog`：不安レベル（`anxiety_level`）、開始・終了日時（`started_at` / `ended_at`）を記録。`user_id`で`User`に紐付く（未ログイン時は`user_id`が`nil`のまま記録可能）

## ローカル環境構築

```bash

docker compose run --rm web bin/rails db:create db:migrate
```
